# Enlarge beat 5 transaction detail screen

## Goal
Make each transaction detail page inside the existing phone mockup fill the available space with larger, presentation-readable content.

## Changes
- Enlarge the merchant name, amount, date, payment rail, original statement, detail labels, checks, and bank insight copy.
- Increase purchase icon size and rebalance spacing so the detail screen uses the phone's width and height more effectively.
- Enlarge the acknowledgment, correction, support, and Undo controls while keeping them within the phone.
- Keep the phone dimensions, transaction content, interaction flow, confirmation state, correction form, and surrounding slide unchanged.
- Retain compact adaptations only where necessary to prevent overflow at the shorter presentation viewport.

## Validation
- Open regular and JFK transaction details at 1540×855 and 1920×1080.
- Confirm all content and actions remain readable and accessible without clipping or unwanted scrolling.
- Test Back, Looks Good, correction, support, and Undo behavior.
- Confirm the transaction list remains unchanged and the preview builds cleanly.
